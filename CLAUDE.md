# CLAUDE.md — working in this repository

commitwork runs a repository's GitHub Actions CI locally and scans it for security defects with a
portable baseline of third-party and own-built checks. Around that core sit a scheduled fleet monitor
(`monitor/`), a local web panel (`admin/`, port 7878), CRA/SOC 2 evidence tooling (`cra/`), an MCP
server (`mcp/`) and viewers (`map/`, `sitemap/`). Zero runtime dependencies; Node 18 or later.

## Commands

```sh
npm test                          # the full suite, through bin/test-run.mjs
node bin/docs-doctor.mjs          # documentation freshness gate (exit 1 orange, 2 grey only)
node bin/commitwork.mjs run <check> --repo <path>   # one check against one repository
node codegraph/report.mjs about <path>              # exports, importers and symbols of a file
```

## House invariants

Apply these to anything you write here. Each exists because breaking it cost something.

- **Report what a check measured.** A check that could not run records why. An unmeasured result is
  neither a pass nor a finding; it goes in its own field, outside the severity buckets.
- **Fail closed.** A parse failure or a permission error is never an empty result. Only `ENOENT`
  means "legitimately absent".
- **Determinism.** Same inputs, byte-identical outputs. Honour `CW_NOW`-style overrides; write
  atomically (tmp + rename, through `writeAtomic` in `monitor/lockfile.mjs`); re-runs are idempotent.
- **Never key a finding's identity on a line number.** Key on place: repo, file, rule, package. A
  finding that moves within a file is the same finding.
- **Every input path is overridable by a `CW_*` environment variable, read at call time**, so the
  suite runs on fixtures. A `const` read at import silently defeats a test that sets the variable later.
- **Declaration is split from authority.** Tools that describe deployments, DNS or tunnels hold no
  credentials and apply nothing.
- **Untrusted by default.** A repository's own `commitwork.json` never executes without
  `--trust-repo-manifest`.
- **Self-contained artifacts.** Generated HTML inlines its data, works from `file://` and loads
  nothing from a CDN.
- **A commit is closed over its own change set.** Nothing committed may import or cite something
  that is not. `bin/test/tracked-imports.test.mjs` checks the committed tree.

## Reading the repository

Several files are too large to read whole. Search to a line, then read a window around it.

| File | Read it by |
|---|---|
| `manifests/security-baseline.json` | `docs/MANIFEST-MAP.md` gives every check's line |
| `admin/serve.mjs` | grep the route; most routes live in `admin/routes/*.mjs` |
| `bin/commitwork.mjs` | grep the command (`cmdRun`, `cmdScan`, `cmdDoctor`) |
| `admin/index.html` | generated from `admin/panel.html` and `admin/menus/*`; never edit it |

The panel's client code is `admin/static/panel-*.js`. Tests read the panel through
`admin/test/lib/panel-source.mjs`, not by slicing HTML.
