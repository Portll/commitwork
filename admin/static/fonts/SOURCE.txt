IBM Plex — vendored, not fetched.
=================================

These eight .woff2 files are served from this panel's own origin (/static/fonts/...). They are NOT
loaded from Google Fonts or any other CDN, and that is a requirement rather than a preference:
this repo ships self-contained artifacts, and the panel's report-only CSP already declares
`default-src 'self'`. A CDN font would have made that policy unenforceable the day someone tried to
enforce it — the fonts would be the violation.

WHICH FILES, AND WHY ONLY THESE
  Upstream ships 208 .woff2 files — every weight, both slopes, split by unicode block. Vendoring
  all of them would be 7.7 MB for a panel that renders English. What is here is the Latin1 split of
  the weights this stylesheet actually asks for:
    Sans  400 Regular · 400 Italic · 500 Medium · 600 SemiBold · 700 Bold
    Mono  400 Regular · 600 SemiBold · 700 Bold
  188 KB in total. Italic is present because three rules set font-style:italic and a synthesised
  oblique of a real italic face is visibly wrong; the bold faces are present so nothing is
  synthesised either.

THE unicode-range IS LOAD-BEARING, NOT AN OPTIMISATION
  Because only the Latin1 split is here, every @font-face in panel.css carries the unicode-range
  upstream declares for it. Without it the browser would consider IBM Plex a candidate for EVERY
  character and draw tofu for the ones this subset does not contain — which is exactly the set the
  panel's status glyphs live in (⧅ ✓ ✕ ■ ▶ ↻ ≡ ⏺). With it, those characters fall through to the
  next family in the stack, as they did before Plex arrived.
